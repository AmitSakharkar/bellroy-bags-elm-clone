# Bellroy Bags Category Page – Elm Clone

This project is a minimalist Elm clone of the [Bellroy Bags category page](https://bellroy.com/products/category/bags). It includes filtering, a responsive grid layout, and clean component structure.

## 🌐 Live Demo

You can compile the project locally and view it in the browser.

## 📦 Features

- Elm SPA (Single Page App)
- Product filtering by category
- CSS grid layout
- Image assets served from `/public`
- Lightweight and easy to extend

## 🛠️ Setup

### Prerequisites

- Elm 0.19.1 installed: [Install Elm](https://guide.elm-lang.org/install/elm.html)

### Build

```bash
elm make Main.elm --output=elm.js
